# Coder Shop App 🛒

Este proyecto fue realizado para enseñar React en Coderhouse

![codershop](/public/img/logo-shop.png)


### Instalación ⚙️

1. Clone el repositorio.
2. Hacer el comando `cd coder-react-93395`.
3. Instale dependencias con el comando `npm install`
4. Para levantar el proyecto de manera local, haga el comando `npm run dev`

> Requisito técnico, es necesario tener Node.js instalado, mínimamente la versión v22.10.0


### Librerias instaladas 📖
- [React Router Dom](): utilizada para la navegación
- [Firebase](): utilizado como base de datos
